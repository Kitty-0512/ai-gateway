# Semantic Layer 轻量验证

> 方法：对 `metrics.yaml` 的 `aliases` / `phrase_rules` 做子串匹配（与线上 `semantic_layer.py` 相同）。  
> **不是 A/B 实验。** 数据集：SEO 内置表（`is_seo_dataset=true` 才会注入）。

匹配规则提醒：别名按 **字符串长度倒序** 遍历，`resolve_primary_metric` 取 **第一个命中** 作为主指标。长词优先，但短词 `流量→pv` 仍可能同时出现在 hits 里。

## 用例

| 用户表达 | 别名命中 | 主指标（resolve） | 期望 | 是否符合 |
|----------|----------|-------------------|------|----------|
| 最近SEO流量怎么样 | `SEO流量`→organic_traffic；另命中短词 `流量`→pv | **organic_traffic** | SEO≠PV | ✓ 主指标对；短词噪音仍在 |
| 自然搜索流量如何 | `自然搜索流量` / `自然搜索` / `搜索流量`→organic；短词流量→pv | **organic_traffic** | organic | ✓ |
| 访问量怎么样 | `访问量`→pv | **pv** | 访问量≈PV | ✓ |
| 网站流量如何 | `网站流量`/`流量`→pv | **pv** | 默认流量=PV | ✓ |
| 搜索流量下降了吗 | `搜索流量`→organic；短词流量→pv | **organic_traffic** | organic | ✓ |
| SEO表现最差的是谁 | `SEO表现`→organic；短语 `SEO表现最差` | **organic_traffic** | organic，勿用 PV | ✓ |
| 独立访客有多少 | `独立访客`/`访客`→uv | **uv** | UV | ✓ |
| 网站表现怎么样 | 无命中 | None | 高度模糊，易歧义 | ✗ 未映射（符合「无法覆盖所有歧义」） |
| 用户数怎么样 | 无命中 | None | 口语≠访客数 | ✗ 无 `用户数` 别名 |

## 观察结果

- **明确同义**（SEO流量、自然搜索、访问量、网站流量、独立访客）**主指标基本正确**。
- 含「流量」的长词仍会 **额外命中** `流量→pv`，依赖「最长优先 + Prompt 里的映射表」纠偏，不是语义消歧。
- **高度模糊**（网站表现、用户数）没有映射，模型仍可能瞎猜 PV/UV。

## 结论

Semantic Layer 对业务指标标准化有明显帮助，但无法解决所有自然语言歧义；后续需要：补别名（如用户数→uv）、或问前澄清「网站表现指 PV 还是 SEO 流量」。
